# Contributing

Thanks for your interest in audiosonde!

**Code contributions are not open yet.** The contribution policy (DCO vs CLA) is
deliberately unsettled: that choice becomes irreversible the moment third-party code is
merged, so it will be decided before the first external pull request lands — with real
contributors in sight, rather than in the abstract.

Until then:

- **Issues are very welcome** — bug reports, bpm/key accuracy reports on real material,
  drift in the README's Fly/Railway recipes, docs gaps, questions about the contract.
- **Security reports**: see [SECURITY.md](SECURITY.md) — please use GitHub private
  security advisories, not public issues.
- **Pull requests will not be merged for now.** You may open one as a discussion artifact,
  but know that it cannot be merged until a contribution policy is in place, and that the
  maintainer may independently re-implement the idea in the meantime.

When contributions open, this file will describe the process (sign-off or agreement, how
analyzers are tested, golden-file conventions). The engineering conventions already live
in [CLAUDE.md](CLAUDE.md) and [docs/](docs/).
