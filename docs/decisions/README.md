# Decisions

Lightweight decision records for choices that were *measured or argued*, not assumed —
e.g. the BPM/key library selection (M5). One file per decision:
`NNNN-short-slug.md` with **Context / Options considered (with measurements) / Decision /
Consequences**. Licensing implications of a decision also go into
[../licensing-policy.md](../licensing-policy.md)'s dependency table.
